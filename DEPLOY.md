# Выкладка сайта FRIDGE

Порядок: **домен → хостинг → связать домен с хостингом → Вебмастер → карточки на картах**.
Сайт запускается **без Яндекс Метрики** (она ставит cookies — это обработка персональных данных).
Код под неё уже есть и спит: включается одной переменной, когда будете готовы (шаг 4).
Названия кнопок в личных кабинетах могут немного отличаться — ориентируйтесь по смыслу.

---

## 1. Домен на Рег.ру

1. reg.ru → найти свободное имя (например, `fridge-nsk.ru`, `remont-fridge54.ru`) → купить на 1 год.
2. При покупке включите **автопродление** (чтобы домен не увели после окончания срока)
   и **защиту персональных данных** в WHOIS (она обычно включена по умолчанию).
3. В профиле Рег.ру включите **двухфакторную авторизацию**.

## 2. Хостинг: Timeweb Cloud → Apps (приложения)

1. timeweb.cloud → зарегистрироваться → включить **двухфакторную авторизацию**.
2. Код сайта должен лежать на GitHub (репозиторий `Anjelaaaaa/fridge`) —
   все последние изменения нужно закоммитить и отправить (push).
3. Раздел **Apps → Создать** → тип **Backend** → **Python / Flask**
   → подключить GitHub → выбрать репозиторий и ветку `main`.
4. Настройки сборки/запуска:
   - файл зависимостей: `requirements.txt`
   - команда запуска:
     ```
     waitress-serve --host=0.0.0.0 --port=8000 app:app
     ```
     (если в форме указан другой порт — поставьте его и в команде)
   - **не** включайте режим отладки / `FLASK_DEBUG` (сайт с ним специально не запустится).
5. **Переменные окружения** (раздел Settings / Переменные):

   | Имя | Значение |
   |---|---|
   | `SITE_HOSTS` | `ваш-домен.ru,www.ваш-домен.ru` |
   | `YANDEX_METRIKA_ID` | **не задавать** — Метрика выключена |
   | `YANDEX_VERIFICATION` | код из Вебмастера (шаг 5), позже |

6. Запустить деплой. Проверить сайт по техническому адресу, который выдаст Timeweb.
   ⚠ Пока задан `SITE_HOSTS`, по техническому адресу сайт отвечает ошибкой 400 —
   это защита. Для проверки добавьте технический адрес в `SITE_HOSTS` через запятую
   или задайте `SITE_HOSTS` уже после привязки домена.

## 3. Связать домен с хостингом

1. В приложении Timeweb: **Домены → Добавить домен** → `ваш-домен.ru` и `www.ваш-домен.ru`.
   Timeweb покажет, какие DNS-записи нужны (обычно `A`-запись с IP или `CNAME`).
2. Рег.ру → Домены → ваш домен → **DNS-серверы и управление зоной** → добавить записи,
   которые показал Timeweb (для `@` и для `www`).
3. Подождать от 15 минут до суток. Timeweb сам выпустит **HTTPS-сертификат** —
   включите его, если это не произошло автоматически.
4. Проверить: `https://ваш-домен.ru` открывается, `http://` перебрасывает на `https://`,
   `https://ваш-домен.ru/robots.txt` и `/sitemap.xml` показывают ваш домен.

## 4. Яндекс Метрика — ПОКА НЕ ВКЛЮЧАЕМ

Включать только после шага 7 (уведомление в Роскомнадзор, политика конфиденциальности,
согласие на cookies на сайте). До этого переменную `YANDEX_METRIKA_ID` не задаём.
Когда будете готовы:

1. metrika.yandex.ru → **Добавить счётчик** → адрес сайта `ваш-домен.ru`.
   Включить **Вебвизор, карту скроллинга и аналитику форм**.
2. Скопировать **номер счётчика** (8–9 цифр) → в Timeweb переменная `YANDEX_METRIKA_ID`
   → перезапустить приложение. Код вставлять на сайт не нужно — он уже подключён.
3. **Цель «звонок»**: Метрика → Настройки → Цели → Добавить цель →
   тип **JavaScript-событие**, идентификатор цели: `call`.
   Сайт отправляет это событие при нажатии на любую кнопку «Позвонить», номер телефона,
   кружок с трубкой в подвале и «Отправить фото».
4. Через 10–30 минут в Метрике появятся первые визиты. Проверить можно,
   открыв сайт и нажав «Позвонить» — событие видно в отчёте «Конверсии».

> Сравнивайте число целей `call` с реальными звонками: если нажатий заметно больше,
> чем звонков дошло, — звонки перехватываются по пути (см. переадресацию на SIM).

## 5. Яндекс Вебмастер

1. webmaster.yandex.ru → **Добавить сайт** → `https://ваш-домен.ru`.
2. Способ подтверждения **Мета-тег**: из строки
   `<meta name="yandex-verification" content="XXXXXXXX" />` скопировать только `XXXXXXXX`
   → в Timeweb переменная `YANDEX_VERIFICATION` → перезапустить → в Вебмастере «Проверить».
3. После подтверждения:
   - **Индексирование → Файлы Sitemap** → добавить `https://ваш-домен.ru/sitemap.xml`;
   - **Информация о сайте → Региональность** → Новосибирск;
   - **Переезд сайта** → отметить HTTPS и главное зеркало без `www`;
   - (позже, когда включите Метрику) привязать её: Настройки → Счётчики Метрики.
4. То же для Google: search.google.com/search-console → мета-тег →
   переменная `GOOGLE_VERIFICATION`.

## 6. Яндекс Бизнес и 2ГИС (для местной выдачи — важнее всего)

- business.yandex.ru и account.2gis.com → подтвердить организацию,
  указать адрес, телефон, часы работы, **ссылку на сайт**, добавить фото.
- Регулярно проверять, что в карточках стоит **ваш** номер.

## 7. Закон о персональных данных (152-ФЗ)

Метрика использует cookies, это считается обработкой персональных данных.
До запуска Метрики на сайте нужны **политика конфиденциальности** и **уведомление о cookies**,
а также уведомление Роскомнадзора об обработке ПДн (pd.rkn.gov.ru), если его ещё нет.
